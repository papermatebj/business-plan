등장인물: customer(고객 앱), hq(통합 관리자: 회원 조회·사업자 인증 관리, nav 예: ['대시보드','회원','사업자 인증','제재']), system(월 1회 국세청 재조회 배치).
상태 칩: 페이지 안에서 'MEMBER_JOIN' 머신 정의 — 화면 단계임을 note에 밝힘: LOGIN 로그인 선택 → TERMS 약관 동의 → IDENTITY 본인인증 → JOINED 가입 완료 → BIZ_VERIFY 사업자 인증 → BIZ_MEMBER 사업자 회원. 곁가지: UNDERAGE 만 19세 미만, DUP_CI 이미 가입됨, BIZ_MANUAL 서류 심사 대기, BIZ_DENIED 휴·폐업. (필요하면 회원 상태 칩 ACTIVE/SANCTIONED/WITHDRAWN 추가)
기본 흐름: 로그인 화면(카카오·애플 버튼, iOS 애플 필수 안내, 이메일 로그인, 로그인 없이 둘러보기) → 카카오(외부: 카카오 로그인) → 처음이면 약관 동의(전체 동의 + 필수/선택 구분, 선택은 기본 해제, 마케팅 채널별(앱 푸시·브랜드 메시지·이메일)과 야간 21~08시 따로, 만 19세 이상 확인) → 휴대폰 본인인증(외부: PASS — 결과 이름·생년월일·CI, 서버 간 조회만 믿음) → 만 나이 계산(member.min_age) → 가입 완료 화면의 "사업자 인증하고 사업자가 보기" → 사업자 인증(사업자등록번호 10자리 하이픈 자동 + 실제 국세청 사업자번호 검증번호 계산식으로 형식 검사, 대표자명, 개업일자) → 외부: 국세청 진위·상태 조회 → 계속사업자 → 상호·업태·종목·업종(10개 공통 코드)·사업장 주소·세금계산서 이메일 입력 → 사업자 회원 전환. 전환 전/후에 같은 상품 카드의 가격 표기가 바뀌는 것(일반가 vs 사업자가 + 공급가 병기, 사업자 배지)을 보여준다(가격 표기 규칙 brief 491~498줄).
예외 갈래: 만 19세 미만(멈추고 결과 저장 안 함), 이미 가입된 CI(가입 방식 일부 가려 안내), 국세청 진위 3회 불일치 → 사업자등록증 올리기 → hq 수동 심사 대기열에서 승인/반려(사유 코드), 휴업·폐업 → 인증 불가, 같은 사업자번호 4번째 계정 → 막고 상담 안내(member.biz_accounts_max), 이메일 가입 대안(인증번호 6자리 5분, 비밀번호 8~20자 2종 이상 검증 문구), 회원 탈퇴(진행 중 주문·클레임·디자인·멤버십이 있으면 불가 사유, 재가입 30일 제한 member.rejoin_block_days).
hq 화면: 회원 상세에서 개인정보 기본 마스킹(홍*동, 010-****-1234), "마스킹 해제"는 사유 입력 필수 → 감사 로그 기록. system: 월 1회 사업자 상태 재조회 배치 → 폐업 감지 → 30일 유예 후 사업자 혜택 해제(시계로 체험).

상태 칩: 엔진 'PARTNER_APP' + 페이지 안 'PARTNER_ACCOUNT'(ACTIVE / PAUSED 파트너 휴점 / SUSPENDED 본사 정지 / TERMINATED 계약 종료).
기본 흐름(맞춤 인쇄 파트너 "대성포장"): 입점 신청 — 담당자 본인인증(외부 PASS) → 사업자등록번호 입력 시 국세청 진위·상태 자동 조회(외부) → 회사 정보, 판매 카테고리 다중 선택에 따라 필수 서류 자동 변경(식품 접촉 → 시험성적서, 위생용품 → 신고증), 맞춤 인쇄 Y → 보유 인쇄 방식 + 인쇄 샘플 발송 안내, 출고지·반품지, 정산 계좌(외부: 쿠콘 예금주 확인, 예금주 = 상호/대표자), 과세 유형 자동 → 제출(SUBMITTED) → hq: MD 배정·REVIEWING(서류 체크리스트 + MD 평가, 점수는 내부용) → SAMPLE_CHECK(맞춤 인쇄만) → APPROVED → 전자 계약 발송(CONTRACT) → partner: 계약 조건 자동 채움(commission.default_rate / custom_rate, 신규 입점 −2%p 3개월, 주 1회 정산, 평가·페널티는 MVP 기록만), 필수 조항 하나씩 동의(직거래 금지·고객 비유인 / 판 소유권·사용 조건 / 회사 디자인 저작권·무단 인쇄 금지 — "법률 자문 전 초안" 표시, 개인정보 처리 위탁, 맞춤 품질 기준), 기존 거래 고객 명단(선택) → 전자서명(외부: 모두싸인) → ACTIVE → 대표 계정 2단계 인증 → 상품 등록 메뉴 열림(catalog.html 링크).
예외 갈래: SUPPLEMENT(보완 항목만 열림, 14일 미응답 자동 반려 — 시계), REJECTED(사유 분류, partner.reapply_days 뒤 재신청 가능일), 휴·폐업 자동 반려, 계좌 인증 3회 실패 → 통장 사본 수동, 계약 14일 미서명 리마인드.
hq 추가: A-PTN-02 적용 요율 미리보기(GC.settle.finalRate, 하한 적용 표시, 30만원 예시 수수료), 계정 상태 조작(휴점·재개, 본사 정지 사유 필수, 계약 종료 → 최종 정산 30% 90일 유보), 직거래 위약금 계산 예시(초안: 금액 × 수수료율 × 3배, 최소 partner.circumvent_penalty_min, 증빙 있을 때만, 소명 7일).
